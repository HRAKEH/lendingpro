## Как развернуть первый лендинг
Из **исходного ZIP**, а не из текущей заглушки GitHub: на сервер переносится `public/index.html` и `public/assets/*.webp` с сохранением структуры. См. [публикация](docs/DEPLOYMENT.md).

## Проверка структуры технических прототипов
```bash
python tools/check_project.py
```

Важно: репозиторий на момент последней проверки был публичным. Не хранить в нём токены, пароли, заявки с персональными данными. Для приватной разработки перевести репозиторий в Private.
