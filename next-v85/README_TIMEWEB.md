# ЗДРАВА — минималистичные лендинги v8.5

Две готовые папки `hot-ice/` и `mikozacid/`. HTML/CSS/JS без сборки.

Дизайн: спокойные фоны, типографика Onest/Golos Text и одна большая редакционная предметная сцена для каждого продукта. Смена трёх эпизодов управляется прокруткой на десктопе. На мобильных — статичная версия без тяжёлой анимации. Ненужный прогресс-бар курса полностью убран. Ингредиенты имеют симметричные внутренние отступы.

Исходные `assets/product.png` — неизменённые файлы v8. Есть `assets/product-premium.webp` со сглаженными границами из фотографии: это не создание новой упаковки, текст и логотип не перерисовывались. Подписи на исходниках всё ещё ограничены оригинальным разрешением, идеальную высокую чёткость обеспечит только снимок высокого качества.

Публикация: извлечь ТОЛЬКО папки двух продуктов в подтверждённый document-root Timeweb рядом с корневым index.html (его НЕ перезаписывать). robots.txt и sitemap.xml здесь оставлены как ЧЕРНОВИК и не должны заменять действующие корневые файлы сайта.

До рекламного запуска: проверить фактический состав и маркировку; подтвердить адрес домена, правомерность утверждений, добавить Метрику при наличии ID, провести Lighthouse на опубликованных страницах. Пока страницы намеренно остаются с noindex,nofollow.
