# Минимальная motion-система v8.5

Один scroll-driven эпизод на сайт, без GSAP, Lenis и других CDN. JS плавно интерполирует позицию, угол и масштаб фото товара (0–4 градуса, 0.99–1.1x) через requestAnimationFrame и меняет редакционную подпись по трём главам. Без декоративного шума, блёсток, морфинга упаковки или псевдо 3D.

На <=820px сцена статична, с одной доступной подписью; функциональные разделы ниже предоставляют всю информацию. При prefers-reduced-motion сцена статична. Якорные ссылки, FAQ/состав <details>, две ссылки маркетплейсов работают без JS. Трекер метрики не активирован без ID.
