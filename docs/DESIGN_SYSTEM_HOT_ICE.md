# Дизайн-система: «Горячий лёд»

**Статус: УТВЕРЖДЕНО пользователем 27.10.2026.**
Одобрено направление **Ice Premium (Б)**, палитра **C2 (Glacier Blue)**, шрифты **F1 (Manrope + Golos Text)**. Утверждение касается визуальной системы, **не** внешнего вида реальной упаковки, содержания или финальной страницы.

## Палитра

| Роль | CSS-переменная | HEX |
|---|---|---|
| Основной фон | `--color-bg` | `#F2F8FD` |
| Текст / заголовки | `--color-text` | `#102B46` |
| Кнопки, ссылки, акцент | `--color-primary` | `#236AA5` |
| Вторичный фон, ледяной градиент | `--color-soft` | `#C5E8F5` |
| Текст на кнопке | `--color-on-primary` | `#FFFFFF` |

Тема брендинга: **светлый, холодный, премиальный** дизайн без агрессивного тёмно-синего фона. Оранжевый не входит в **утверждённую** палитру: добавлять его только после отдельного согласования.

## Типографика

- **Заголовки:** Manrope, вес **800**, возможен 700 для подзаголовков. Пример: «Комфорт в твоём ритме».
- **Основной текст:** Golos Text, вес **400**, выделения 500–600. Пример: «Ежедневный уход за телом».
- Резервные семейства: Arial / system-ui / sans-serif.
- Кириллица и реальная загрузка гарнитур должны быть проверены при просмотре HTML онлайн; предыдущие офлайн PNG могли показывать fallback.

## Подача

- Минимум декоративного шума, акцент на товаре и свободном пространстве.
- Допустимы холодные градиенты, чистые структурные линии, умеренное движение. Без обязательного огня/оранжевого.
- Крупные чёткие заголовки, простые CTA на карточки товара.
- Адаптивность 360, 390, 768, 1024, 1440 px; поддержка `prefers-reduced-motion`.

## Не утверждено

- Окончательное фото упаковки тубы 50 мл и/или банки 250 мл.
- Утверждённые свойства, точный продуктовый текст, ссылка конечного SKU, наличие и согласованный макет.
- Конкретная сетка секций за пределами выбранной общей стилистики.

Название «Горячий лёд» — образ для дизайна, не доказательство температурного, лечебного или обезболивающего эффекта. Перед запуском сверить формулировки с этикеткой и статусом продукта.
