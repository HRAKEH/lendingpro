# Предварительный выбор товаров для следующих лендингов

Дата анализа: 2026-10-27. Статус: **предварительные рекомендации, заказчиком ещё не утверждены**.

## Рекомендую

### 1. Крем для ног и пяток с мочевиной «Кубанская бурёнушка»
- Преимущество для лендинга: конкретная задача ухода за сухой кожей и огрубевшими пятками; поисковые запросы понятны.
- На публичных маркетплейсах существуют конкурирующие кремы с мочевиной с большим количеством отзывов — это подтверждает наличие аудитории категории, **не продажи именно этого товара**.
- Товарная карточка на Ozon: https://www.ozon.ru/product/krem-dlya-nog-i-pyatok-s-mochevinoy-kubanskaya-burenushka-3854582898/
- WB: https://www.wildberries.ru/catalog/942931425/detail.aspx
- Потребуется отдельно собрать и проверить оригинальные изображения и утверждённые описания; не копировать свойства конкурентов на лендинг.

### 2. Крем для тела «Ланолин», туба 50 мл
- Преимущество для лендинга: понятный ингредиент и узнаваемая ниша ухода за сухой кожей.
- Для него, согласно рабочим материалам, уже подготовлены товарные визуалы, есть карточки на двух площадках.
- Важно подтвердить фактический состав, назначение, безопасность и допустимые заявления. Нельзя автоматически называть крем 100%-ным ланолином, средством для сосков или лечением псориаза.
- WB: https://www.wildberries.ru/catalog/1912305798/detail.aspx
- Основной Ozon URL перед запуском брать из актуальной товарной карточки/бизнес-документации.

## Ограничения оценки
- Исследованы заполненные товарные позиции рабочей Google-таблицы и открытые страницы товарных категорий.
- Таблица включает повторяющиеся товары в кабинетах разных продавцов; количество товарных строк не равно количеству уникальных SKU.
- **Нет подтверждённой полной статистики продаж, конверсии, маржи, рекламного бюджета, поисковых объёмов и возвратов**, поэтому нельзя утверждать, что выбранные два товара дадут максимальную прибыль.
- Пример: десятки тысяч отзывов у товара-конкурента — индикатор зрелости ниши, а не прогноз спроса на собственный товар.
- Следующий шаг: получить данные продаж и расходов по SKU, проверить остатки, затем окончательно утвердить два лендинга.
