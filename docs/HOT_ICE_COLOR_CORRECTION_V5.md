# Горячий лёд — цветокоррекция тубы, версия v5

Дата: 2026-10-28.

**Результат:** исходное изображение тубы 349×855 RGBA, поставленное пользователем ранее, скорректировано по цвету без перерисовки упаковки. Серо-лиловый оттенок светлой части уменьшен, белый пластик стал чуть холоднее и светлее, синий ярче. Все буквы, контуры, форма и альфа-маска прозрачности сохранены: это пиксельная коррекция исходника, НЕ новая сгенерированная упаковка.

Файлы в текущем чате:
- `hot-ice-package-color-corrected.png` — прозрачная PNG туба.
- `hot-ice-before-after.jpg` — визуальное сравнение.
- `lendingpro-timeweb-v5-hot-ice-color-corrected.zip` — готовый архив для Timeweb, идентичный v4 за исключением `hot-ice/assets/product.png`.

Проверено локально:
- В обоих ZIP 13 записей; содержимое всех записей, кроме `hot-ice/assets/product.png`, полностью совпадает.
- Изначальная и исправленная упаковки имеют одинаковые RGBA размеры 349×855 и **побайтно идентичный канал Alpha**, поэтому контур и прозрачные края не изменены.
- Целостность ZIP проверена без ошибок.
- Повторная визуализация браузером была недоступна из-за ERR_BLOCKED_BY_ADMINISTRATOR в изолированном Chromium; прежняя QA по v4 применима к неизменённой HTML/CSS/JS структуре, но не заявлять о новом browser-pass.

Это не публикация: сайт Timeweb не менялся. Глобальные тексты и юридические вопросы v4 остаются без изменений. Код и PNG пока прикреплены в архиве чата, **не импортированы в GitHub**.
