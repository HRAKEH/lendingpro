# Лендинги: техническая версия 1.0

Дата: 27 октября 2026 года.

**Архив:** lendingpro-final-timeweb.zip, прикреплён в исходном чате. Включает независимые папки mikozacid и hot-ice, каждая содержит index.html, styles.css, script.js и assets. Исходники **ещё не выгружены в GitHub**. Визуальный макет: https://www.figma.com/design/bF0MkdWDEJOlC07l2cPhUY

## Референсы и выводы
- https://псорифитум.рф/ — понятные разделы состава, применения, FAQ и покупки.
- https://artikulate.ru/ — информационная структура и CTA в разных разделах. Не брать спорную статистику и неподтверждённые медицинские обещания.
- Итог: компактные качественные лендинги без крикливого маркетинга, выдуманных отзывов и декоративных 01/02/03.

## Утверждено
- Оба сайта используют только **два семейства: Onest и Golos Text**. Более ранний Manrope для Горячего льда заменён по последнему указанию пользователя.
- Две кнопки Ozon и Wildberries в первом экране и в нижнем блоке каждого сайта.
- Никаких технических подписей в пользовательском интерфейсе.
- Адаптивные страницы 1440px и 390px, мягкие анимации, мобильное меню, FAQ, reduced-motion. Без сборки и сторонних библиотек JS.

## Проверка
- Chromium при 1440 и 390px: без горизонтальной прокрутки, без JS-ошибок, по 2 ссылкам на Ozon/WB на каждом сайте, мобильное меню открывается.
- В рабочей папке созданы скриншоты desktop/mobile, однако Chromium работал в изолированной среде без загрузки удалённых шрифтов/изображений.
- Четыре нативных макета Figma обновлены: кнопки WB, унифицированная типографика, удаление технических подписей. Проверка последним скриншотом не проведена из-за лимита Figma Starter.

## Не закрыто — фотографии упаковок
- Mikozacid: отсутствует подтверждённый оригинальный файл. Нужен mikozacid/assets/product.webp, именно **Микозацид**, не похожий **Микозоцид**.
- Hot Ice: указан fallback на https://goryachiled.ru/img/product.png; для надежности нужен локальный файл hot-ice/assets/product.webp, с разрешённым использованием.
- Фото не перерисовывать и не обрезать: object-fit: contain.

## Публикация
- Сейчас robots noindex,nofollow: **это предпросмотр, не полностью утверждённая реклама**. Нужно сверить состав и требования с этикетками заказчика, лицензии изображения, убрать noindex после подтверждения.
- При публикации на Timeweb положить обе папки В ФАКТИЧЕСКИЙ корень домена рядом с существующим index.html, не перезаписывая главный сайт ЗДРАВА.
- Никаких изменений на Timeweb этой итерацией не выполнено.
