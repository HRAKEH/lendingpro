# ЗДРАВА — Minimal Editorial v8.5 (28.10.2026)

**Актуальный вариант для визуального согласования.** Локальный архив `ZDRAVA_v8_5_MINIMAL_EDITORIAL.zip` загружен в `releases/`. Две новые папки сайта — `next-v85/hot-ice/` и `next-v85/mikozacid/`. Предыдущие версии, включая `next-v8/` и v8.3, не перезаписывались.

## Что изменено
- Убраны бесконечные ленты, орбиты, частицы, крупные фоновые надписи и лоскутные 3D-блики.
- Hero — один фотореальный оригинальный продукт на спокойном однотонном студийном фоне.
- Одна большая редакционная scroll-driven сцена после блока «О средстве»: при прокрутке 3 естественных смены подписи и лёгкое движение **фотографии** тубы без деформации формы.
- Вместо дополнительных анимационных библиотек используется `studio.js` (requestAnimationFrame, progress via scroll position); на ширине ≤820px и при reduced-motion сцена статична.
- Полностью удалена декоративная полоска «шаг 2/3» под блоком курса, а также глобальный верхний прогресс страницы.
- Отступы **всех трёх карточек состава симметричны** на 360, 390, 768 и 1440px.
- Исходные `assets/product.png` остались побайтово идентичны оригиналам прежней v8. Для показа используется `assets/product-premium.webp` — осторожная 3x ресемплинг/сглаживание кромки **из исходной фотографии, а не ИИ-перерисовка этикетки**.
- Сохранились Onest и Golos Text, CTA Ozon/Wildberries, полные составы, native FAQ, SEO noindex до утверждения.

## Что проверено
Chromium с инлайновой загрузкой локальных CSS/JS и реальных product.webp при недоступности внешней сети:
- Обе страницы: viewport **360, 390, 768, 1440 px**, без горизонтальной прокрутки и pageerror.
- Фото загружаются, CTA на маркетплейсы существуют, мобильное меню и details работают.
- На desktop при прокрутке по фильм-сцене активируется третий эпизод; на mobile — статичный первый.
- Карточки состава имеют одинаковый padding слева и справа, декоративные полоски курса отсутствуют.
- `node --check` скриптов, ZIP `testzip()`, проверка оригинальных PNG.

## Важные ограничения
- Сама фотография тубы имеет ограниченное исходное разрешение, поэтому **идеальной типографской резкости этикетки нельзя добиться цветокоррекцией/upscale**. Для 4K нужна съёмка или исходник высокой чёткости от производителя.
- Метрика без ID не активна; SEO страницы в состоянии `noindex,nofollow`, юридические формулировки и составы требуют подтверждения.
- **Timeweb не изменён.** `robots.txt` / `sitemap.xml` из ZIP не должны перекрывать существующие корневые файлы сайта.
- В GitHub v8.5 хранится отдельно; никакие старые версии не удалены.
