## Лендинг 1 — «Флебодиа»
Пользователь передал готовый архив `flebodia-site-for-developer.zip`. Подробная карта блоков, стилей, ссылок, хешей и файлов: [LANDING_01_ARCHITECTURE.md](LANDING_01_ARCHITECTURE.md).

**Согласован адрес: https://zdrava.ru/flebodia/**. Пользователь подтвердил 27 октября. Публикация пока не подтверждена.

Технически: статический HTML со встроенным CSS, без JS и backend; две локальные WebP картинки. Исходные файлы содержатся в ZIP:
`public/index.html`, `public/assets/hero.webp`, `public/assets/rest.webp`. Локальные ссылки в HTML относительные: папка `flebodia/` на том же домене работает без изменения HTML.

**Timeweb:** нужно выяснить действительный документальный корень сайта `zdrava.ru`, создать внутри `flebodia/` и распаковать в неё **содержимое** `public/`. Не затрагивать файлы основного сайта «ЗДРАВА». Полная инструкция: [DEPLOY_FLEBODIA_ZDRAVA.md](DEPLOY_FLEBODIA_ZDRAVA.md).

**Внимание:** оригинальный HTML и картинки ещё НЕ загружены в `landing-01/` GitHub, там сохраняется техническая заглушка. Для публикации используйте исходный ZIP или `flebodia-timeweb-upload.zip` из чата. ZIP может быть недоступен новому аккаунту, поэтому важно сохранить исходники вне чата.

Перед запуском проверить инструкцию, состав и сведения об изготовителе по этикетке; оригинальный контент автоматически не утверждён.
