## 2026-10-27 — предварительный отбор товаров (актуальная версия)
По пожеланию владельца заменить «Космольгин» из-за внешнего вида упаковки: **«Микозацид» сохраняется, вместо «Космольгина» предварительно предложен «Горячий лёд»**. Основная причина — потенциал дизайна «лёд/огонь» при наличии исторических заказов. У «Горячего льда» небольшой запас, точная упаковка ещё не подтверждена. Прежние идеи «Кубанская бурёнушка» и «Ланолин» по привлекательности тематики **уступают в приоритете после расширенного анализа**. Детали: [PRODUCT_SHORTLIST.md](PRODUCT_SHORTLIST.md).
