## Следующий этап
1. Получить права на подлинные фото/макеты «Микозацида» и «Горячего льда», проверить варианты упаковки и конечные карточки Ozon/WB.
2. Сверить утверждённые продуктовые тексты, состав и ограничения медицинских заявлений с этикетками.
3. Создать **полноценные desktop/mobile макеты** для обоих товаров по утверждённой дизайн-системе и предоставить на оценку.
4. После утверждения макетов выполнить вёрстку и тестирование; не трогать действующий основной сайт или «Флебодиа» без отдельного запроса.

## 2026-10-27 — Инструменты для завершения дизайна
Выбраны 3 специализированных инструмента: **Figma** (UI/UX: требуется подключить), **Adobe Create Mockups** (предметные сцены) и **Adobe Batch Edit Photos** (серийная обработка). Два Adobe-навыка доступны и их инструкции изучены, но Adobe-права на использование конкретных операций ещё надо проверять при работе; Figma не подключена автоматически. Фиксация в [DESIGN_SKILLS.md](DESIGN_SKILLS.md). Согласованные дизайны C1/F1 и C2/F1 не меняются.

## 2026-10-27 — Без шаблонного ИИ-дизайна
Пользователь особо подчёркивает: дизайн должен выглядеть как качественная работа настоящего дизайнера, без типовых ИИ-эффектов. **Видимые номера шагов/разделов пишутся 1, 2, 3; НЕ 01, 02, 03.** Можно обходиться без номеров. Политика: [DESIGN_QUALITY_RULES.md](DESIGN_QUALITY_RULES.md). В Figma https://www.figma.com/design/bF0MkdWDEJOlC07l2cPhUY пока не были обнаружены готовые экраны на момент инспекции; не считать сайт готовым.
