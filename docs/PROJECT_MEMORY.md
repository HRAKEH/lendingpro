## Главный факт на текущий момент

**Лендинг №1: «Флебодиа».** Пользователь передал архив `flebodia-site-for-developer.zip`. Архив исследован; создана полная техническая карта: [LANDING_01_ARCHITECTURE.md](LANDING_01_ARCHITECTURE.md), а также [BRIEF_LANDING_01.md](BRIEF_LANDING_01.md).

- Продукт: косметический крем для ног, 50 мл.
- Цель лендинга: переход на страницу продукта Ozon.
- Архив: `README.txt`, `public/index.html`, `public/assets/hero.webp`, `public/assets/rest.webp`.
- Весь CSS внутри HTML, JS отсутствует, две WebP картинки. Одна страница; адаптивные стили. Семь тематических секций + шапка/подвал.
- Хостинг, который обсуждался: Timeweb. В прошлом на нём размещался сайт «ЗДРАВА»; нельзя перезаписывать его файлы.
- **GitHub содержит пока документы и исходную техническую заглушку лендинга №1. Оригинальный HTML/картинки Флебодиа в GitHub ещё НЕ загружены.**
- **Флебодиа НЕ отмечена опубликованной.** Домен, DNS и работающий HTTPS пока не подтверждены.

**Лендинг №2:** назначение, бренд, исходники, стиль и домен ещё не определены; в `landing-02/` только техническая заглушка.

## Организация репозитория

- `docs/BRIEF_LANDING_01.md` — подтверждённые исходные факты первого лендинга.

## Безопасность
При последней проверке репозиторий имел видимость **Public**, несмотря на рекомендацию Private. Не класть в него закрытые коммерческие сведения, пароли, заявки или токены. Для скрытой разработки пользователь может изменить видимость через настройки GitHub.

## Текущие задачи
1. По возможности скопировать **оригинальный**, а не выдуманный HTML/CSS и оба WebP первого лендинга в GitHub (`landing-01/`).
2. Уточнить назначение домена для Флебодиа, создать в Timeweb отдельный сайт и разместить именно содержимое `public/`.
3. Проверить описание крема, этикетку, производителя, правовые требования, ссылки и HTTPS.
4. Получить бриф лендинга №2.
5. После каждой работы обновлять этот файл и `CHANGELOG.md`.
