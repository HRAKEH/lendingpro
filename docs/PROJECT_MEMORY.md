# PROJECT MEMORY: актуальное состояние LendingPro

**Дата:** 2026-10-27  
**Репозиторий:** https://github.com/HRAKEH/lendingpro  
**Этап:** 0: инфраструктура подготовлена, брифы не заполнены.  
**Статус сайта:** имеются только технические страницы-заглушки, никакой окончательный дизайн не согласован.

## Цель проекта
Создать **два независимых лендинга**, вести дизайн, исходники и решения в этом репозитории, чтобы продолжать работу после смены чата или аккаунта.

## Подтверждено
- Пользователь запросил два лендинга.
- Нужен один GitHub-репозиторий со всеми проектными файлами, журналом решений и контекстом.
- Пользователь дал ссылку на созданный репозиторий HRAKEH/lendingpro.
- По состоянию на начало работы репозиторий **PUBLIC**, хотя рекомендована приватная видимость.
- Подключение GitHub имеет право записи в этот репозиторий.
- Для проверки дизайна важен просмотр на реальных размерах экранов; возможно использовать браузер в режиме ChatGPT Work.

## Выбранная временная архитектура
- Два автономных каталога: `landing-01/` и `landing-02/`.
- На начальном этапе чистые HTML/CSS/JS, без зависимости от сборщика и фреймворка.
- Каждый лендинг может развёртываться на собственном домене либо отдельном пути.
- Не добавляем выдуманные адреса, отзывы, цифры, интеграции и обработчики заявок.
- Страницы содержат noindex, пока используются как прототипы. Перед запуском SEO пересматривается.

## Неизвестно
- Для чего каждый лендинг и что должен делать посетитель.
- Бренды, целевые аудитории, тексты, референсы, изображения.
- Адреса, домены, хостинг, требования к формам и обработке данных.
- Сроки, бюджет, финальный стек.

## Следующее действие
1. Получить краткое описание назначения **обоих** лендингов.
2. Заполнить `docs/BRIEF_LANDING_01.md` и `docs/BRIEF_LANDING_02.md`.
3. Уточнить аудитории, CTA, стиль, референсы.
4. Согласовать структуру, потом дизайн, затем разработку.
5. По желанию владельца сделать репозиторий приватным через GitHub Settings → General → Danger Zone → Change repository visibility.

## Правила передачи контекста
В новом чате открыть и прочитать: README, этот файл, TASKS, DECISIONS, CHANGELOG, оба BRIEF, WORKFLOW. Не выдавать незаполненные поля за факты. После существенных правок обновлять память проекта и список задач, указывать реальный коммит. Работать с GitHub можно после подключения нового аккаунта к тому же репозиторию.
