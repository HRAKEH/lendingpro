## Визуальное решение v8
Созданы **два отдельных новых HTML-файла с нуля**, а не косметическая переработка старых v7.
- **Микозацид:** botanical editorial, кремовый/светло-зелёный, тонкие круглые линии и товарная туба, основная зелёная CTA, асимметричная спокойная композиция.
- **Горячий лёд:** glacier editorial, холодный голубой, кристаллообразная плашка за тубой, ледяная палитра.
- **Шрифтовые семейства ровно 2 на проект:** Onest для заголовков и логотипа, Golos Text для текста и интерфейса.
- Оригинальные PNG туб сохранены **побайтово без изменения**, размеры: Микозацид 468×734, Горячий лёд 349×855.
- Отдельно созданы OG JPG 1200×630 и SVG favicon. OG использует наложение прежней прозрачной PNG тубы без перерисовки.

## Анимация и производительность
- Текст line-reveal, мягкий scroll reveal, mouse-reactive декоративные формы (без изменения изображения тубы), scroll-progress, кнопки с hover, разовый счётчик количества на desktop, подвижная панель Ozon/WB на mobile.
- CDN GSAP + ScrollTrigger и Lenis — прогрессивное улучшение; **весь контент, ссылки и FAQ работают без JS/CDN**. Нативное меню доступно также через noscript-стили.
- Тяжёлые движения отключены при `prefers-reduced-motion`; Lenis не активируется в мобильном размере.
- Встроенные CSS/JS в index.html уменьшают количество локальных запросов; исходные независимые версии стилей и скриптов также сохранены для правок, но страницы их отдельно не грузят.
- Tailwind CDN намеренно **не включён**: вместо него кастомный inline CSS, чтобы не добавлять блокирующую зависимость и не создавать шаблонность.
- Изображения hero имеют width/height и fetchpriority; другие images lazy.
- Performance ≥90, CLS<0.1, LCP<2.5с — **целевые показатели; не измерены**.

## SEO и разметка
- Два уникальных title (<60) и description (<160), canonical по **домену из мастер-ТЗ `https://zdrava.top`**.
- OG / Twitter Card + локальные оригинальные OG JPG; JSON-LD Organization, Product, FAQPage.
- **НЕТ фиктивных Offer с неизвестной ценой и availability InStock**. Google требует реальную цену для валидного Offer; отсутствие таких данных честнее обозначить пропуском. (https://developers.google.com/search/docs/appearance/structured-data/product-snippet)
- FAQPage само по себе **не гарантирует** расширенный сниппет в Google: он ограничен избранными авторитетными сайтами (https://developers.google.com/search/blog/2023/08/howto-faq-changes).
- `robots.txt` и `sitemap.xml` **шаблоны**, их нельзя перезаписывать на корне существующего основного сайта, пока не подтверждены домен и публикация.
- Обе страницы пока имеют `noindex,nofollow`.

## Яндекс Метрика
На странице есть `data-event` и обработчик для кликов Ozon/WB/Где купить, просмотра раздела покупки, раскрытия состава. **Счётчик не установлен** — без ID и включения он не отправляет данные. В коде `window.ZDRAVA_METRIKA_ID=null`.

## QA
