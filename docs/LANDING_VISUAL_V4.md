# LendingPro — финальная визуальная сборка с тубами (v4)

Дата: 2026-10-28. Статус: **готово для предпросмотра и тестовой загрузки на Timeweb, ещё не утверждено для рекламного запуска**.

## Актуальный артефакт
В чате проекта создан ZIP: **lendingpro-timeweb-v4-with-original-packages.zip**.

В нём две отдельные папки:
- mikozacid/index.html, styles.css, editorial.css, script.js, assets/product.png
- hot-ice/index.html, styles.css, editorial.css, script.js, assets/product.png

Встроенные изображения туб извлечены из **переданных пользователем JPEG**: IMG_0817.jpeg — Микозацид, IMG_0816.jpeg — Горячий лёд. Прозрачные маски, сохранённые исходные пропорции, надписи, логотипы и фактура оригинальных фото. **НЕ ИИ-реконструкция упаковки**. Третий файл IMG_0818.jpeg использован только как визуальный референс концепции, **не копировался** на сайты.

## Дизайн
- Новая редакционная верстка, асимметричный split hero, один крупный предметный кадр, мягкие графические линии, содержательные секции.
- Микозацид — одобренный нефритовый Clinical Minimal; Горячий лёд — ледяной Ice Premium.
- **Строго две семьи Onest и Golos Text на обеих страницах**.
- Ozon и Wildberries: по две ссылки на каждый маркетплейс в каждом лендинге.
- Состав, применение, FAQ из предоставленных описаний. Нумерация 1, 2, 3 без ведущих нулей. Мягкие анимации и reduced-motion.
- Никакой перерисовки упаковок и никаких технических подписей на пользовательской странице.

## Проверено
Проверка Chromium с inline asset embedding на ширинах **360, 390, 768, 1440 px**: у обоих товаров фото загружается, object-fit contain, нет горизонтального overflow и JS pageerrors; CTA видны и мобильное меню открывается. Созданы desktop и mobile скриншоты в папке артефакта. По текущим условиям тестовый браузер отображает fallback шрифты, на хостинге должны загрузиться веб-шрифты через Google Fonts.

## Оставшиеся содержательные проверки
- Фотография тубы «Горячий лёд» содержит слова **«гель для тела»**, но первоначальный текст заказчика в некоторых местах использует слово «крем». На новой странице название категории приведено к фото: «гель для тела». До коммерческого размещения уточнить фактическое обозначение продукта и этикетку.
- У Hot Ice упаковка содержит **«водоросли»**, которых нет в предоставленном полном составе. Эта характеристика не добавлена в текст страницы, но несоответствие источников нужно проверить у заказчика.
- Для Микозацида маркетинговое описание на исходном изображении содержит компоненты, отсутствующие в полном ингредиентном списке. В лендинге не используется рекламная надпись вокруг упаковки, а продуктовый текст не включает спорные ингредиенты.
- Не выдвигать медицинских обещаний без документального подтверждения; точность составов и правомерность описаний необходимо подтвердить по упаковке/производителю.
- У обоих сайтов остаётся robots noindex,nofollow до согласования публичной публикации.

## Размещение и фиксация
- Создан только локальный архив для Timeweb и картинки предпросмотра. **На хостинге изменений нет.**
- **Сам HTML/CSS/JS/PNG набор пока не загружен в GitHub**: информация и статус сохранены здесь. ZIP необходимо сохранить из текущего чата при переносе проекта. Предыдущие технические репозиторные заглушки не являются обновлённым релизом.
- При распаковке поместить папки mikozacid и hot-ice в подтверждённую корневую папку домена рядом с существующим index.html. Основной сайт ЗДРАВА и Флебодиа не трогать.
