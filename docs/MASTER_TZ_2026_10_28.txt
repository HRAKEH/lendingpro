ТОН КОНТЕНТА (жёсткое правило)
- Никаких обещаний лечения, исцеления и «эффективности против». Только уход, комфорт, свежесть, ритм.
- Формулировки «по описанию товара», «сверьтесь с упаковкой», «если есть зуд/изменения — обратитесь к врачу» — сохранить в FAQ.
- Юридический дисклеймер в футере обязателен.
- Кнопки «Купить» ведут только на Ozon/WB с пометкой «цена и доставка в карточке товара». Форму заявки не ставить.

ДИЗАЙН (тренды — осознанно, 2–4 на проект, не всё сразу)
- Крупная выразительная типографика: заголовки большим кеглем, акцентные слова другим весом/цветом/шрифтом.
- Шрифты: Google Fonts, современные пары (Manrope, Space Grotesk, Unbounded, Inter). Не Arial/system-ui как основной.
- Палитра: у Горячего льда — прохладная (глубокие мятно-голубые акценты), у Микозацида — свежая спокойная (зелёно-древесные акценты). Точные HEX — в концепции.
- Bento-сетка для блоков сценариев и состава, воздушные отступы, 1 яркий акцентный цвет, без радуги.
- Лёгкие текстуры (grain/noise) или mesh-градиенты в hero — по вкусу, без перегруза.

СКРОЛЛ-АНИМАЦИИ (двухуровневая система)
Базовый уровень (обязателен):
- Lenis — плавный скролл.
- Построчное появление заголовков (SplitType или аналог), reveal-эффекты секций по ScrollTrigger.
- Стаггер карточек, счётчики на цифрах (50 мл, 30/21 день), hover-состояния кнопок и карточек.
Дополнительный уровень (выбрать 1–2, не больше):
- Pin-секция «Применение» со сменой шагов по скроллу.
- Marquee-строка (бегущие ключевые слова).
- Прогресс-бар чтения.
- Параллакс-изображения.
Правило: каждый эффект должен вести взгляд к следующей секции или к CTA. Эффект, который ничего не продаёт, — убрать. На мобильных — только лёгкий fade, pin и тяжёлые эффекты только на десктопе. Поддержка prefers-reduced-motion: тяжёлые анимации отключаются.

ТЕХНИЧЕСКИЙ СТЕК
- Один файл index.html + (опционально) assets/. Tailwind CSS через CDN.
- Библиотеки только: GSAP + ScrollTrigger, Lenis, SplitType, Swiper (если нужен слайдер). Ничего сверх.
- Все анимации — только transform/opacity, срабатывание один раз (once), без дёрганья при обратном скролле.
- Страница полностью работоспособна без JavaScript (контент виден, аккордеоны работают нативно).
- Адаптив mobile-first: контрольные точки 360, 768, 1440. Тач-цели минимум 44×44.
- Семантика: header, nav, main, section, article, footer; один H1; правильная иерархия H2/H3.

SEO (продвинутый уровень)
Мета-теги:
- Title: до 60 символов, формула «{Товар} — {назначение} | ЗДРАВА». Пример: «Микозацид — уход за стопами и ногтями | ЗДРАВА».
- Description: до 160 символов, с названием товара, брендом и «купить на Ozon и Wildberries».
- Canonical на собственный URL, favicon, lang="ru".
Структурированные данные (JSON-LD):
- @type: Product — название, описание, бренд ЗДРАВА, image, объем.
- offers: два элемента с вашими ссылками Ozon и Wildberries (url, availability InStock, priceCurrency RUB). Цену не вшивать, только ссылки — актуальную цену показывает площадка.
- @type: Organization (brand) с сайтом zdrava.top.
- FAQPage разметка для секции вопросов (это даёт расширенный сниппет в выдаче).
Open Graph + Twitter Card: og:title, og:description, og:image (1200×630), og:url, og:type product.
Контент под брендовые запросы: «микозацид», «горячий лёд гель для тела», «микозацид купить», «горячий лёд купить». Запрещён keyword stuffing («купить дёшево бест цена») — Яндекс пессимизирует.
Alt-тексты для всех изображений с названиями товара и зон применения.
Технические файлы: сгенерируй robots.txt (с Allow всем, ссылкой на sitemap.xml) и sitemap.xml со всеми URL проекта.

ПРОИЗВОДИТЕЛЬНОСТЬ (бюджет жёсткий)
- Цель: Lighthouse Performance ≥ 90 на мобильных, CLS < 0.1, LCP < 2.5 c.
- Изображения: WebP/AVIF, width/height указаны (иначе CLS), lazy loading ниже первого экрана.
- Скрипты: defer, GSAP-CDN с async где возможно; шрифты — display=swap, preconnect.
- Без jQuery, без тяжёлых фреймворков, без лишних CDN.
- Логотип и иконки — инлайн-SVG (Lucide-подобные), не растровые картинки.
