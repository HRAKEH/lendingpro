# Рабочий процесс

1. Перед изменениями прочитать `README.md`, `PROJECT_MEMORY.md`, `TASKS.md`, нужный бриф.
2. Не заменять неизвестное предположением без явной пометки «гипотеза».
3. Каждый лендинг редактировать внутри собственной папки.
4. Перед коммитом провести проверку: `python tools/check_project.py`; при визуальных правках также проверить браузер.
5. В том же коммите обновлять `PROJECT_MEMORY.md`, `TASKS.md`, `CHANGELOG.md` и решения, если они менялись.
6. После коммита давать ссылку, перечислять изменённые файлы, пройденные и непройденные проверки.

## Новый чат или новый аккаунт
1. Подключить GitHub с доступом к репозиторию.
2. Передать `https://github.com/HRAKEH/lendingpro`.
3. Попросить: «Прочитай README, docs/PROJECT_MEMORY.md, docs/TASKS.md, docs/DECISIONS.md, docs/CHANGELOG.md и оба BRIEF. Продолжи со следующей задачи».
4. История чата не требуется, если проектная документация актуальна.

## Визуальная проверка
Использовать тестовые URL или скриншоты в ширинах 360, 390, 768, 1024 и 1440 px. При доступном режиме ChatGPT Work можно тестировать сайты через браузер.

## Безопасность
Не хранить в GitHub секреты, пароли, заявки с персональными данными, приватные ключи. Заполнять только достоверные публичные данные, особенно пока репозиторий публичен.
