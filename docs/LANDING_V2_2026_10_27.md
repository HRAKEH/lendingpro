# Лендинги v2: оригинальный подход без копирования и выдуманных сведений

Дата: 27.10.2026. Статус: **рабочий прототип v2 для ревью, не финальная публичная публикация**.

## Решение владельца
- Предоставленные референсы `псорифитум.рф` и `artikulate.ru` — только уровень исполнения, **не шаблоны** для копирования.
- Дизайн должен быть своим: выразительная современная типографика, продуманная асимметрия, индивидуальные ритмы секций и анимация по смыслу.
- Использовать **только официальные/первичные источники для фактических продуктовых утверждений**. Если нет подтверждения — не писать; не создавать цифры, отзывы, результаты и эффект лечения.
- Оба лендинга используют **только Onest для заголовков и Golos Text для основного текста**.
- Кнопки **Ozon и Wildberries** на первом экране и внизу. Видимая нумерация, когда она уместна, **1, 2, 3**, без ведущего нуля. Без технических текстов на клиентской странице.
- Фотографии подлинных упаковок — без генерации этикеток, обрезки, изменения формы и надписей.

## Что сделано в v2
Подготовлен локальный ZIP `lendingpro-distinct-v2.zip` в чате. В нём статические директории:
- `mikozacid/index.html`, `styles.css`, `script.js`;
- `hot-ice/index.html`, `styles.css`, `script.js`;
- `DEPLOY_AND_SOURCES.txt` (только внутренняя инструкция, не копировать в публичную корневую директорию).

Две страницы адаптивные; проверены 1440/390/360px, вёрстка не создаёт горизонтального переполнения. Реализованы микроанимация CTA, стрелки, лёгкое появление секций, аккордеон FAQ, мобильное меню, `prefers-reduced-motion`, работа без сложной сборки. Не придуманы отзывы и статистика.

## Источники
- Для **Микозацида** подтверждены название, назначение и объём по товарной карточке, но **официальный источник изготовителя не найден**. Состав и способ применения намеренно не переписаны в клиентский лендинг. Нельзя использовать фотографию **«Микозоцида»**: другое наименование и упаковка. Изображения Микозацида до сих пор нет; в hero только фирменная типографика, **не изображение упаковки**.
- Для **Горячего льда** использованы название, формат «крем» и объём 50 мл. Фото тубы задано внешним URL `https://goryachiled.ru/img/product.png`, со страницы, **представляющейся официальным сайтом**. **Совпадение с конкретным SKU заказчика пока не подтверждено**; при недоступности картинки она скрывается и ничего не подменяется. Никакие спорные заявления о пользе, эффективности, сертификатах не перенесены. Перед выпуском нужно проверить производителя и этикетку.
- Пользовательские карточки Ozon/WB из рабочей Google-таблицы используются как адреса переходов; это не доказательство подлинности всех формулировок.
- Дизайн-тренды рассмотрены по Shopify 2026 https://www.shopify.com/in/blog/ux-design-trends и Webflow 2026 https://webflow.com/blog/web-design-trends-2026.
- Примеры `https://псорифитум.рф/` и `https://artikulate.ru/` не копировались.
