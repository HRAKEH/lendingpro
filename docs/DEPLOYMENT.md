# Развёртывание на Timeweb

## Флебодиа (лендинг №1): готовый статический сайт

**Исходный архив:** `flebodia-site-for-developer.zip`.  
**Точная архитектура:** [LANDING_01_ARCHITECTURE.md](LANDING_01_ARCHITECTURE.md).  
**Статус:** размещение, DNS и HTTPS пока не подтверждены.

Сайт уже содержится в папке `public` внутри ZIP. Не нужен Node.js, npm, PHP, API, база данных и сборка.

В панели Timeweb следует **создать отдельный сайт и отдельный корневой каталог**, чтобы не трогать ранее размещённый проект «ЗДРАВА». После назначения домена/поддомена загрузить **содержимое** `public/` (не лишнюю папку `public`) в корень этого сайта:

```text
public_html/
├── index.html
└── assets/
    ├── hero.webp
    └── rest.webp
```

Далее проверить A/CNAME/NS по данным панели Timeweb и регистратора; выпустить TLS-сертификат; открыть `https://<уточнённый-домен>/`. Проверить меню-якоря, шесть раскрывающихся блоков, две картинки, ссылки на Ozon, страницу на телефоне.

**Перед публичным запуском:** сверить сведения о креме, составе, инструкции и изготовителе с официальной этикеткой и требованиями законодательства. В исходном `README.txt` изготовитель не заполнен.

## Варианты размещения
Два лендинга можно разместить на двух разных доменах либо на поддоменах одного основного. Корневые каталоги должны быть независимы. Не перезаписывать существующий сайт.

## Дополнительно
Для продуктового SEO по подтверждённому домену можно добавить `canonical`, favicon, Open Graph, robots.txt, sitemap.xml. Не подставлять выдуманные адреса. Пароли и доступы держать только в защищённом хранилище.
