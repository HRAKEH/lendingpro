# Публикация лендингов

`landing-01/` и `landing-02/` являются самостоятельными статическими сайтами.

## На разных доменах
Создать на хостинге отдельные корневые директории для каждого сайта. Поместить **содержимое** каждой папки в корень соответствующего сайта так, чтобы файл `index.html` лежал на верхнем уровне.

## На одном домене
Если задача допускает, папки могут жить по адресам `/landing-01/` и `/landing-02/`.

## Перед публикацией
1. Уточнить домены, хостинг, DNS.
2. Развернуть соответствующие файлы сайта; проверить CSS/JS.
3. Подключить SSL/TLS и убедиться, что сайт открывается по HTTPS.
4. Проверить адаптивность, работающие CTA, отсутствие ошибочных ссылок.
5. Настроить индексацию: временный noindex у технического прототипа убрать **только после согласования запуска**.
6. Зафиксировать итоговые URL в брифах и PROJECT_MEMORY.md.

Фактические доступы и пароли не публиковать.
