## Материалы для просмотра

- [HTML-галерея в GitHub](../design-review/round02.html).
- В исходном чате есть архив `lendingpro_approval_round2.zip` с 8 HTML-примерами (1440px) и мобильными/десктопными PNG.
- В снимках без сетевого доступа Onest, Golos Text и Manrope могли заменяться системными шрифтами. Для проверки финальных шрифтов открыть HTML с корректной загрузкой Google Fonts или локальных лицензированных WOFF2.

Изображения оригинальных упаковок и финальные продуктовые тексты **пока не утверждены**. HTML-галерея — история сравнения, а не код публичного сайта.
