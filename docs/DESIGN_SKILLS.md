# Набор из трёх инструментальных навыков для финализации дизайна

**Дата отбора:** 2026-10-27.  
**Задача:** закончить два товарных лендинга («Микозацид», «Горячий лёд») с реальными предметными изображениями, редактируемыми макетами и единым качеством графики. Дизайн-системы уже утверждены.

## 1. Figma — UI/UX и адаптивные макеты
- **Назначение:** создавать/править макеты экранов, дизайн-компоненты и варианты для ПК и мобильных; согласовывать с пользователем, передавать в код.
- **Статус:** приложение Figma найдено в каталоге ChatGPT; **не подключено**. Пользователю предложено подключение, оно требует его собственного действия.
- **Ограничение:** работа напрямую с Figma через подключение возможна только после фактической авторизации; без неё можно делать HTML/CSS-прототипы в GitHub.

## 2. Adobe Create Mockups — предметные композиции
- **Skill:** `skills://plugins/app-69312da8e4dc81919370cb86fd172b6c/adobe-create-mockups/skill.md`
- **Назначение:** презентационные мокапы товара, сцены вокруг оригинальной упаковки, согласование первого образца до серии.
- **Статус:** скилл доступен и его инструкции прочитаны. Выполнение требует доступных Adobe инструментов и при необходимости входа; авторизация не проверена.
- **Защита точности:** сохранять реальную форму, надписи и пропорции тубы/банки из фотографий заказчика; не выдавать сгенерированную этикетку за подлинную.

## 3. Adobe Batch Edit Photos — единый стиль изображений
- **Skill:** `skills://plugins/app-69312da8e4dc81919370cb86fd172b6c/adobe-batch-edit-photos/skill.md`
- **Назначение:** одинаковая обработка серии реальных товарных фото: свет, тон, кадрирование, визуальная согласованность.
- **Статус:** скилл доступен и его инструкции прочитаны. Для обработки нужны оригинальные изображения и доступные Adobe инструменты; авторизация не проверена.
- **Защита точности:** фотографии должны сохранять узнаваемость и фактическую идентичность упаковки.

## Дополнительный уже доступный навык (вне тройки)
- Adobe Fonts — изучены инструкции скилла `adobe-fonts`. Палитры и шрифты уже **утверждены**, поэтому не переоткрывать их без запроса. Микозацид: Onest + Golos Text, C1. Горячий лёд: Manrope + Golos Text, C2.

## Порядок выполнения
1. Подтвердить возможность работы в Figma (или использовать репозиторий GitHub и HTML-макеты вместо неё).
2. Получить фотографии **точных SKU** и права на использование.
3. Подготовить 1–2 товарные сцены и согласовать композицию.
4. Привести остальные изображения к единой цветовой обработке.
5. Создать ПК/мобильные макеты по дизайн-системам: `docs/DESIGN_SYSTEM_MIKOZACID.md` и `docs/DESIGN_SYSTEM_HOT_ICE.md`.
6. Согласовать полноразмерные макеты, затем реализовать сайты в коде и проверить в браузере.

## Важно
Этот файл документирует выбранные навыки и источники инструкций, **не устанавливает** плагины автоматически и не создаёт постоянное расширение аккаунта. Для продолжения в другом чате снова прочитать этот файл и подключить необходимые приложения.
