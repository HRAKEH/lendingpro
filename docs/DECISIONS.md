# Журнал решений

## 2026-10-27: один репозиторий, два независимых сайта
- **Решение:** проект размещается в `HRAKEH/lendingpro`; исходники сайтов разнесены по папкам.
- **Причина:** единая документация и восстановление контекста; независимое развёртывание.
- **Согласование:** пользователь прислал ссылку на репозиторий.

## 2026-10-27: минимум инструментов на старте
- **Решение:** чистый HTML/CSS/JS для технических прототипов.
- **Причина:** лёгкое размещение на обычном статическом хостинге и быстрые правки.
- **Статус:** временно; окончательный стек зависит от брифов.

## 2026-10-27: репозиторий публичен
- **Факт:** пользователь создал репозиторий с видимостью Public.
- **Риск:** любой может читать исходники и документацию.
- **Рекомендация:** сменить видимость на Private до добавления коммерческих сведений.
